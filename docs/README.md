# Documentation

This directory will contain the public, versioned documentation for 172X Command Marketplace.

Planned documentation includes:

- extension manifest and package schemas;
- compatibility and versioning policy;
- capability and permission reference;
- Theme, Widget, Panel, and Command authoring guides;
- local validation and testing;
- package review, trust labels, deprecation, takedown, and security response;
- registry/catalog format and release process.

No public extension contract is stable yet. Examples or proposals added during the private
pre-release phase must identify their provisional status and must not be represented as supported
172X Command behavior.
